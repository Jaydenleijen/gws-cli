Privacy policy

Last updated 13 October 2026.

gws CLI is a personal tool. Its only user is the owner of this page, signing in to their own Google account.

What it accesses

With the owner's permission, the tool reads and organises the owner's own Gmail, Calendar, Drive, Docs, Sheets, Tasks and Contacts data when the owner runs it.

How data is handled

Data is processed on the owner's own computer. It is not sold, shared with third parties, used for advertising, or stored on any server operated for this tool. Sign-in credentials are stored encrypted on the owner's computer and can be revoked at any time from the Google account's security settings.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
